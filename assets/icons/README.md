# KorhanORS Icon Pack v1

Klasor: `assets/icons/`

Tum ikonlar inline SVG formatindadir ve `currentColor` kullanir. Bu sayede ikon rengi CSS ile kontrol edilir.

Ornek kullanim:

```html
<img src="/assets/icons/github.svg" alt="GitHub">
```

Not: SVG icinde `stroke="currentColor"` oldugu icin, inline SVG olarak kullanilirsa renk parent elementten alinir. `img` ile kullanirken renk degistirmek istersen CSS filter gerekir. En pratik kullanim ilk etapta siyah/beyaz ikon seklindedir.
